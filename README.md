# AI Question Paper Analyzer V10

V10:
- improves original figure extraction by expanding the AI crop and grouping
  nearby PDF drawing/image objects, including outer wires and labels;
- renders common LaTeX answer delimiters in Streamlit;
- provides ICSE/ISC subject catalogues;
- provides examination years 2015–2027;
- uses bundled official-syllabus data when available;
- for an unbundled selection, lets the user upload the official CISCE syllabus
  PDF and extracts its hierarchy for that analysis.

Initially bundled:
- ICSE Class X Physics 2026
- ISC Class XII Physics 2027

The year/subject catalogue does not claim that every historical syllabus has
already been verified and bundled. For unbundled selections, use the official
CISCE syllabus PDF as the source of truth.
